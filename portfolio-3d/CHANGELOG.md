# Changelog

Semua perubahan penting pada proyek ini akan didokumentasikan di file ini.

## [1.0.0] - 2024-11-17

### ✨ Initial Release

#### Added
- 🎨 Hero section dengan animasi 3D sphere dan floating shapes
- 👤 About section dengan rotating 3D cube interaktif
- 💼 Projects section dengan 6 project cards interaktif
- 🛠️ Skills section dengan visualisasi 3D sphere untuk setiap skill
- 📧 Contact section dengan form dan 3D torus animation
- 🧭 Sticky navigation dengan glass effect dan active indicators
- ⭐ Particle field dengan 5000+ partikel
- 🌟 Stars background menggunakan Three.js
- 🎭 Smooth animations menggunakan Framer Motion
- 📱 Fully responsive design untuk semua device
- 🎨 Glass morphism effects
- 🌈 Gradient color scheme
- ♿ Accessibility features
- 🔍 SEO optimized
- ⚡ Performance optimized dengan lazy loading

#### Components
- `AnimatedSphere.tsx` - Animated 3D sphere dengan distorsi
- `FloatingShapes.tsx` - Multiple floating 3D shapes
- `ParticleField.tsx` - Particle system dengan 5000+ partikel
- `HolographicCard.tsx` - Holographic card effect
- `Navbar.tsx` - Sticky navigation dengan glass effect
- `LoadingScreen.tsx` - Loading screen dengan animasi
- `Hero.tsx` - Hero section dengan 3D background
- `About.tsx` - About section dengan 3D visualization
- `Projects.tsx` - Portfolio projects showcase
- `Skills.tsx` - Skills dengan 3D visualization
- `Contact.tsx` - Contact form dengan 3D torus

#### Tech Stack
- Next.js 15 dengan App Router
- TypeScript untuk type safety
- Three.js & React Three Fiber untuk 3D graphics
- @react-three/drei untuk 3D helpers
- Framer Motion untuk animations
- Tailwind CSS untuk styling
- GSAP support untuk advanced animations
